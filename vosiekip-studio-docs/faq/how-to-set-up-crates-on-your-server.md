# How do I set up crates on my server?

**Short answer:** install a **crate plugin**, create crates with rewards, and hand out **keys** through voting, quests, events or your store. Place the crates in a central spot at spawn.

***

{% stepper %}
{% step %}
### Install a crate plugin

Popular options include **ExcellentCrates** and **CrazyCrates**. Both let you create crates with rewards, animations and holograms.
{% endstep %}

{% step %}
### Create crates and rewards

Make a few crate types, such as Vote, Common and Rare, each with their own rewards.
{% endstep %}

{% step %}
### Hand out keys

Give keys for voting, quests, playtime and events. That keeps crates fun for every player.
{% endstep %}

{% step %}
### Build a crate area

Place your crates together in an easy-to-find spot at spawn. All our lifesteal spawns have a crate area.
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
**Selling keys for real money?** Paid random rewards come close to gambling, which Mojang doesn't allow. Keep paid crate rewards cosmetic, see [making money without pay-to-win](how-to-make-money-without-pay-to-win.md).
{% endhint %}
