# How do I add a rank table to my store?

**Short answer:** a rank table shows all your ranks side by side, with ticks and crosses for each perk. Neither Tebex nor PayNow has one by default, but all our themes and Tebex websites include one as an add-on.

***

### Why a rank table helps sales

Players compare before they buy. A table that shows what the next rank adds makes upgrading an easy choice.

### How to add one

| Your store                | How                                                                                              |
| ------------------------- | ------------------------------------------------------------------------------------------------ |
| Legacy Tebex store        | Upload `ranktable.twig` and enter your rank category ID, see the [Tebex theme guide](../tebex-theme-guides/installation-guide.md). |
| PayNow store              | Upload `ranktable.html` and enter your rank category, see the [PayNow theme guide](../paynow-guides/installation-guide.md). |
| Our Tebex website         | Install the **Rank Table** add-on and fill in the features, see [Add-ons](../tebex-website-guides/add-ons.md). |

Empty table? See [Why is my rank table empty?](why-is-my-rank-table-empty.md)
