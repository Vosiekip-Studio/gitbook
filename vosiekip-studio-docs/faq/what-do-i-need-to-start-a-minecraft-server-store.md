# What do I need to start a Minecraft server store?

**Short answer:** a webstore platform (**Tebex** or **PayNow**), its plugin on your server, a few products with good images, a design that matches your server, and knowledge of Minecraft's rules for selling.

***

### Checklist

| You need                 | What it is                                                         | Read more |
| ------------------------ | ------------------------------------------------------------------ | --------- |
| **A webstore platform**  | Handles payments, taxes and delivery to your server.               | [Tebex or PayNow?](tebex-or-paynow.md) |
| **The store plugin**     | Runs the commands on your server after a purchase.                 | [Set up Tebex](how-to-set-up-a-tebex-store.md) · [Set up PayNow](how-to-set-up-a-paynow-store.md) |
| **Products**             | Ranks, cosmetics, keys or a currency.                              | [What should I sell?](what-should-i-sell-on-my-minecraft-server-store.md) |
| **Graphics**             | An image for every package, so the store looks finished.           | [Icons and banners](where-to-get-icons-and-banners-for-your-store.md) |
| **A design**             | A store that looks like your server, not a default template.       | [Make your store look better](how-to-make-your-tebex-store-look-better.md) |
| **The rules**            | What Minecraft allows you to sell.                                 | [Make money without pay-to-win](how-to-make-money-without-pay-to-win.md) |

{% hint style="info" %}
Start small. Three or four well-made ranks with clear perks sell better than twenty confusing packages.
{% endhint %}
