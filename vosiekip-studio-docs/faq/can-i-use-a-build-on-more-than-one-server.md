# Can I use a bought build on more than one server?

**Short answer:** on your **own** servers, usually yes. Products on BuiltByBit with the **Standard license** can be used in unlimited projects that **you own and control**. You can't share or resell the files, and you can't use one copy for servers you build for other people.

***

### What the Standard license allows

According to [BuiltByBit's license page](https://builtbybit.com/wiki/resource-eulas/):

| Allowed                                         | Not allowed                                      |
| ----------------------------------------------- | ------------------------------------------------ |
| Use on all servers **you own and control**      | Sharing or reselling the files                   |
| Changing the files to fit your server           | Using one copy on servers you make for clients   |

{% hint style="warning" %}
Check the license on the product page. Some products use a different license than the Standard one.
{% endhint %}

### Building servers for clients?

Each client's server needs its own copy. Buy a copy per client, or ask the client to buy it.
