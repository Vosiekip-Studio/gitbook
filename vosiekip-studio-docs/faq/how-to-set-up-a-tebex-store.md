# How do I set up a Tebex store for my Minecraft server?

**Short answer:** create a Tebex account and store, connect your server with the Tebex plugin, add your packages with the commands they should run, then give your store a design that fits your server.

***

{% stepper %}
{% step %}
### Create your store

Sign up at [tebex.io](https://www.tebex.io/) and create a store. Pick the right game type:

* **Minecraft Java Edition** for a Java-only server.
* **Minecraft Offline** for a crossplay server (Java and Bedrock).
{% endstep %}

{% step %}
### Connect your server

1. Install the **Tebex plugin** on your server.
2. In the Tebex Creator Panel, open **Integrations → Game Servers** and copy your server's **secret key**.
3. In your server console, run `tebex secret <key>` with your key.

Tebex can now deliver purchases to your server.
{% endstep %}

{% step %}
### Add packages

Create categories (such as Ranks, Keys, Coins) and packages inside them. For each package, add the **commands** your server runs after a purchase, for example a command that gives a rank.

{% hint style="warning" %}
Follow Minecraft's rules for selling on servers. See [How do I make money without pay-to-win?](how-to-make-money-without-pay-to-win.md)
{% endhint %}
{% endstep %}

{% step %}
### Make it look good

Add package images and a design that fits your server. See [How do I make my Tebex store look better?](how-to-make-your-tebex-store-look-better.md) and [Where can I get icons and banners?](where-to-get-icons-and-banners-for-your-store.md)
{% endstep %}
{% endstepper %}

For all details, see [Tebex's own setup checklist](https://docs.tebex.io/creators/initial-setup-guide/tebex-project-launch-checklist-from-account-to-activation).
