# How do I set up a PayNow store for my Minecraft server?

**Short answer:** create a store in the PayNow dashboard, connect your server with PayNow's plugin, add your products with the commands they should run, and install a theme so the store matches your server.

***

{% stepper %}
{% step %}
### Create your store

Go to the [PayNow dashboard](https://dashboard.paynow.gg/webstore) and create a store. Pick the right game type:

* **Minecraft Java Edition** for a Java-only server.
* **Minecraft Offline** for a crossplay server (Java and Bedrock).
{% endstep %}

{% step %}
### Connect your server

Install PayNow's plugin on your server and connect it to your store with the key from your PayNow dashboard. PayNow's own docs show the exact steps for your server software.
{% endstep %}

{% step %}
### Add products

Create your products (ranks, keys, coins) with the commands your server runs after a purchase.

{% hint style="warning" %}
Follow Minecraft's rules for selling on servers. See [How do I make money without pay-to-win?](how-to-make-money-without-pay-to-win.md)
{% endhint %}
{% endstep %}

{% step %}
### Install a theme

PayNow lets you upload your own theme in its template editor. See our [PayNow theme installation guide →](../paynow-guides/installation-guide.md)
{% endstep %}
{% endstepper %}
