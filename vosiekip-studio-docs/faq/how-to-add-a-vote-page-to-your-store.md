# How do I add a vote page to my store?

**Short answer:** a vote page lists all your server's voting sites with a button for each. All our themes and Tebex websites include a **Vote Page** add-on: create a page in your store, match the title, and add your vote links.

***

### Why a vote page

Votes push your server up on server lists, which brings new players. One page with every voting link makes voting quick, so players do it more often.

### How to add one

1. Create a page in your store (in Tebex: [creator.tebex.io/pages](https://creator.tebex.io/pages)).
2. Turn on the **Vote Page** add-on and type the page title **exactly** as you named the page.
3. For each voting site, fill in a button text and link.

Page not showing? See [Why is my vote page not showing?](why-is-my-store-page-not-showing.md)

{% hint style="info" %}
**Want rewards for voting?** That happens on your server, not in your store. A plugin such as **NuVotifier** receives votes from server lists, and a vote rewards plugin gives the reward.
{% endhint %}
