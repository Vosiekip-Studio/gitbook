# What are the best plugins for an SMP server?

**Short answer:** keep the base close to vanilla with the usual **essentials**, then add **long-term goals**: skills, jobs, quests and a shop. That keeps SMP players busy without changing what makes survival fun.

***

### The essentials

| Plugin type        | Examples                     | Why                                     |
| ------------------ | ---------------------------- | --------------------------------------- |
| Permissions        | LuckPerms                    | Ranks and permissions.                  |
| Basics and economy | EssentialsX + Vault          | Homes, teleports, money.                |
| Land claims        | A claims plugin              | Players protect their own builds.       |
| Logging            | CoreProtect                  | See and undo griefing.                  |
| Menus              | DeluxeMenus + PlaceholderAPI | Clean menus, see [What is DeluxeMenus?](what-is-deluxemenus.md) |

### Long-term goals

* **Skills,** see [mcMMO or AuraSkills?](mcmmo-or-auraskills.md)
* **Jobs,** see [jobs without breaking your economy](how-to-set-up-jobs-without-breaking-your-economy.md)
* **Quests** and **playtime rewards**, see [keeping players coming back](how-to-keep-players-coming-back.md)
