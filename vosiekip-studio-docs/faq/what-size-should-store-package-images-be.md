# What size should package images be on Tebex and PayNow?

**Short answer:** use **square** images (the same width and height), for example **512×512 pixels**, saved as a **PNG with a transparent background**. Keep every package image the same size and style.

***

### Our recommendations

| Setting      | Recommendation                     | Why                                                    |
| ------------ | ---------------------------------- | ------------------------------------------------------ |
| Shape        | Square (1:1)                       | Most store themes show package images in a square box. |
| Size         | 512×512 pixels                     | Sharp on all screens, still small to load.             |
| Format       | PNG with a transparent background  | Fits on any store background color.                    |
| File size    | As small as possible               | Big images make your store slow.                       |

{% hint style="info" %}
These are our recommendations, not a rule from Tebex or PayNow. Check how your theme shows images and adjust if needed.
{% endhint %}

### Keep it consistent

* Use the **same size** for every package, otherwise the store looks messy.
* Keep the item **centered**, with a bit of empty space around it.
* Use **one style** for all images: don't mix drawn and 3D images.
