# What is DeluxeMenus, and do I need it?

**Short answer:** DeluxeMenus is a free plugin that lets you create **custom menus** (inventory GUIs) for your server with config files. You need it if a configuration you use is built on it, like most of our configurations.

***

### What it does

DeluxeMenus turns a config file into a clickable menu. A menu can open with a command, show items with information, and run commands when a player clicks. Server owners use it for skill menus, rewards, warps, rules and more.

### Do I need it?

* **Using one of our configurations?** Most of them include DeluxeMenus menus, for example mcMMO, AuraSkills, JobsReborn, CrazyEnchantments and Playtime Rewards. Then yes, install DeluxeMenus.
* **Want custom menus yourself?** It's one of the most used menu plugins, with a big community.

### What else you need

DeluxeMenus works together with **PlaceholderAPI**, which shows live info in menus, such as a player's level or balance. Install both.

More info: [DeluxeMenus wiki](https://wiki.helpch.at/helpchat-plugins/deluxemenus).
