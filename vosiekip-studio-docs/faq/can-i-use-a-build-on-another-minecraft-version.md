# Can I use a spawn on an older or newer Minecraft version?

**Short answer:** **newer** is fine, **older** is not. Minecraft can load a build made for an older version, but not one made for a newer version. That's why our builds come in a separate file for every Minecraft version.

***

### Why older versions can't load newer builds

Every Minecraft update adds new blocks. A build made in a new version can contain blocks that an older version doesn't know, so the older server can't load it.

### Picking the right file

Our downloads have a file for each version, ending in `_to_` and the version number. Pick the one for your server's version, or the closest version **below** it.

| Your server version | Pick the file ending in |
| ------------------- | ----------------------- |
| `1.21.9`            | `_to_1.21.9`            |
| `1.21.8`            | `_to_1.21.6`            |
| `1.20.1`            | `_to_1.20`              |

See the [build installation guide →](../build-guides/installation-guide.md) for more.
