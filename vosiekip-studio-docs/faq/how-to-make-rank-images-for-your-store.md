# How do I make rank images for my store?

**Short answer:** give every rank its **own color** and make higher ranks look **more valuable**, while keeping the same style for all of them. Design them yourself, or start from a ready-made rank graphics pack.

***

### What makes a good rank image

* **Clear tiers.** Each rank should look a step up from the one before, for example with more detail, glow or a bigger item.
* **One color per rank.** Use the same color as the rank's chat prefix, so players recognize it in-game.
* **Readable names.** If the rank name is on the image, it must be readable at small sizes.
* **Same size and style** for every rank, see [What size should package images be?](what-size-should-store-package-images-be.md)

### Upsell variants

Use a slightly different image for **rank upgrades** (from one rank to the next) so players see right away it's an upgrade, not a new rank.
