# Can I use a Tebex theme on a new Tebex store?

**Short answer:** not right now. Tebex has turned off custom HTML and CSS for **new** stores on its new storefront system, and says it is working on bringing it back. Custom themes still work on **older (legacy) stores** with a **Tebex Plus** subscription.

***

### What changed

Tebex moved new stores to a new storefront system. On those stores, full HTML and CSS editing is currently unavailable, so a custom theme can't be installed. Custom templates also need **Tebex Plus**. See [Tebex's Appearance docs](https://docs.tebex.io/creators/tebex-control-panel/webstore/appearance).

### How do I know if my store is "legacy"?

If your store was created before the new storefronts and you can still open the **template editor** under **Appearance**, you're on the legacy system. Then a theme still works, see our [Tebex theme installation guide →](../tebex-theme-guides/installation-guide.md).

### What can I use instead?

| Option                 | What it is                                                                                     |
| ---------------------- | ---------------------------------------------------------------------------------------------- |
| **Tebex website**      | Your own website on your own domain, with your packages and payments still in Tebex. Works for every store. |
| **PayNow theme**       | Switch your store to PayNow, which allows custom themes. See [Tebex or PayNow?](tebex-or-paynow.md) |
| Tebex's default look   | Change logo, colors and header in **Appearance**.                                             |

{% hint style="info" %}
**Tebex websites for all our theme designs are coming soon.** See [Tebex theme or Tebex website?](tebex-theme-or-tebex-website.md)
{% endhint %}
