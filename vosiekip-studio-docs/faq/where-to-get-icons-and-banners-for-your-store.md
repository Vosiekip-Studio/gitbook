# Where can I get icons and banners for my Tebex or PayNow packages?

**Short answer:** you can design them yourself, hire a designer, or use a ready-made **graphics pack**. Packs are the quickest way to give every package a matching, professional image. Start with our **free crate keys pack**.

***

### Your options

| Option                 | Good for                                 | Downside                         |
| ---------------------- | ---------------------------------------- | -------------------------------- |
| Design it yourself     | Full control, no cost                    | Takes time and design skills     |
| Hire a designer        | A unique look                            | Costs more, takes longer         |
| **Graphics pack**      | Matching images for every package, today | Other servers can use the same pack |

### What to look for in a pack

* **A full set** in one style: ranks, keys and currency should look like they belong together.
* **Transparent PNGs**, so they fit any store background.
* **Tiers**, so higher ranks or bigger bundles look more valuable.

See also [What size should package images be?](what-size-should-store-package-images-be.md)
