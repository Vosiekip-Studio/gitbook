# How do I add cosmetics like hats to my server?

**Short answer:** add the hat models with a custom item plugin (**ItemsAdder**, **Nexo** or **Oraxen**), then give them to players as rewards or sell them. Cosmetics are one of the safest things to sell, because they don't make anyone stronger.

***

### How to add hats

1. Install a custom item plugin, see [ItemsAdder, Nexo or Oraxen?](itemsadder-vs-nexo-vs-oraxen.md)
2. Add a model pack with hats, see the [model installation guide →](../model-guides/installation-guide.md)
3. Players wear the hat in their helmet slot.

### Selling cosmetics

Mojang's [usage guidelines](https://www.minecraft.net/en-us/usage-guidelines) allow selling cosmetics, **except capes** or anything that looks like a cape. See [making money without pay-to-win](how-to-make-money-without-pay-to-win.md).

{% hint style="info" %}
Cosmetics work great as rewards too: in a battle pass, for playtime or for finishing quests.
{% endhint %}
