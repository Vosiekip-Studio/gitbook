# How do I start a Hypixel-style skyblock server?

**Short answer:** start with a **skyblock plugin** and good **islands**, then add the systems that make Hypixel SkyBlock fun: **skills**, a **bazaar**, **collections and quests**, and lots of areas to explore. It's a big project, so a ready-made setup saves months of work.

***

### What a Hypixel-style skyblock needs

| System               | What it does                                    | Read more |
| -------------------- | ----------------------------------------------- | --------- |
| Skyblock plugin      | Gives every player their own island.            | Check the plugin's docs. |
| Islands              | Starter and themed islands to unlock.           | [Where to get islands](where-to-get-skyblock-islands.md) |
| Skills               | Farming, mining, combat and more that level up. | [mcMMO or AuraSkills?](mcmmo-or-auraskills.md) |
| Bazaar               | Players trade with each other through orders.   | [Hypixel-style bazaar](how-to-add-a-hypixel-style-bazaar.md) |
| Quests               | Goals that guide players through the game.      | [Adding quests](how-to-add-quests-to-your-server.md) |
| Custom items         | Weapons, tools and armor beyond vanilla.        | [Custom tools and weapons](how-to-add-custom-tools-and-weapons.md) |
