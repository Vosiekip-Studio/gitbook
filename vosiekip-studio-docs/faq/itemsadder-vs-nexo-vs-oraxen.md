# ItemsAdder, Nexo or Oraxen: which should I pick?

**Short answer:** already using one of them? Keep it, our models work with all three. Starting fresh? **ItemsAdder** has the most built in, **Nexo** and **Oraxen** are simpler and lighter to set up.

All three plugins do the same basic job: they add custom items, furniture and blocks to your server with a resource pack. The difference is in how much they include and how you set them up.

***

### ItemsAdder

The most complete of the three. It comes with lots of extras built in, such as resource pack hosting, menus and emojis.

* **Good for:** servers that want one plugin that does everything.
* **Keep in mind:** paid, and the first setup has more steps.

### Oraxen

A lighter plugin with a simple setup: one config file per group of items.

* **Good for:** servers that want a simple, no-nonsense setup.
* **Keep in mind:** fewer extras built in, so you may need other plugins for menus.

### Nexo

The newest of the three. Its setup is close to Oraxen's, so moving from Oraxen to Nexo is easy.

* **Good for:** new servers that like Oraxen's simple setup.
* **Keep in mind:** newer, so there are fewer guides and ready-made packs for it online.

***

### Quick comparison

|                       | ItemsAdder   | Oraxen       | Nexo         |
| --------------------- | ------------ | ------------ | ------------ |
| Built-in extras       | Most         | Few          | Some         |
| Ease of setup         | More steps   | Simple       | Simple       |
| Works with our models | ✅            | ✅            | ✅            |
