# How do I add custom tools and weapons to my server?

**Short answer:** install a custom item plugin (**ItemsAdder**, **Nexo** or **Oraxen**) and add a model pack. The plugin gives the items their own look with a resource pack, so players don't need mods.

***

{% stepper %}
{% step %}
### Pick a plugin

Already have one? Use that. Otherwise see [ItemsAdder, Nexo or Oraxen?](itemsadder-vs-nexo-vs-oraxen.md)
{% endstep %}

{% step %}
### Add a model pack

Upload the pack's files to your plugin's folder and rebuild the resource pack. See the [model installation guide →](../model-guides/installation-guide.md)
{% endstep %}

{% step %}
### Give the items to players

Hand them out as rewards, in crates, in a shop or in quests. Get one yourself with the plugin's menu: `/ia`, `/nexo inv` or `/oraxen inv`.
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
Selling powerful weapons for real money can break Mojang's rules. See [making money without pay-to-win](how-to-make-money-without-pay-to-win.md).
{% endhint %}
