# How do I change the look of my PayNow store?

**Short answer:** install a **PayNow theme**. Create a new template in the PayNow dashboard, open the template editor and drag the theme's files in. Texts, colors and extra pages are set up in the template settings.

***

### How it works

1. Create a new template in the PayNow dashboard.
2. Open the **template editor**.
3. Unzip the theme and drag all files from its `0. Theme` folder into the editor.
4. Set up the extras, such as a staff, vote or FAQ page, rank table or gift cards.

Every step with screenshots: [PayNow theme installation guide →](../paynow-guides/installation-guide.md)

{% hint style="info" %}
According to [PayNow](https://paynow.gg/compare/tebex), custom HTML and CSS are included on its free plan, so you don't need a paid plan for a custom theme.
{% endhint %}
