# Schematic or world download: which should I use?

**Short answer:** use the **schematic** if you want to paste the build into a world you already have. Use the **world download** if you want the build as its own separate world. Every one of our builds comes with both.

***

### Side by side

|                      | Schematic                                  | World download                              |
| -------------------- | ------------------------------------------ | ------------------------------------------- |
| What it is           | Just the build, as one file                | A complete world with the build in it       |
| How to install       | Paste it with FastAsyncWorldEdit           | Upload the folder to your server            |
| Server restart       | Not needed                                 | Needed                                      |
| Best for             | Adding a build to an existing world        | A separate spawn or hub world               |

### Pick the schematic if…

You want the build next to your current spawn, inside your survival world, or anywhere in an existing map. See [Pasting with FAWE →](../build-guides/pasting-with-fawe.md)

### Pick the world download if…

You want a separate spawn world that players teleport to, or want to use the build as your main world. See [Uploading the world folder →](../build-guides/uploading-the-world-folder.md)
