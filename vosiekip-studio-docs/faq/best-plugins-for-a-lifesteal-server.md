# What are the best plugins for a lifesteal server?

**Short answer:** you need a **lifesteal plugin** for the heart system, the usual **essentials** (permissions, protection, economy), and extras that give players goals between fights, such as **quests**, a **battle pass** and a **shop**.

***

### The essentials

| Plugin type        | Examples                    | Why                                          |
| ------------------ | --------------------------- | -------------------------------------------- |
| Lifesteal          | A lifesteal plugin          | Steals and loses hearts on kills and deaths. |
| Permissions        | LuckPerms                   | Ranks and permissions.                       |
| Basics and economy | EssentialsX + Vault         | Homes, teleports, money.                     |
| Protection         | WorldGuard                  | Protects spawn, see [protecting your spawn](how-to-protect-your-spawn-from-griefing.md). |
| Logging            | CoreProtect                 | See and undo griefing.                       |
| Menus              | DeluxeMenus + PlaceholderAPI | Clean menus, see [What is DeluxeMenus?](what-is-deluxemenus.md) |

### Extras that keep players playing

* **A shop** made for PvP, see [balancing shop prices](how-to-balance-shop-prices.md).
* **Quests** and a **battle pass** for daily goals.
* **Crates** for rewards, see [How do I set up crates?](how-to-set-up-crates-on-your-server.md)

See [What is a lifesteal spawn?](what-is-a-lifesteal-spawn.md)
