# How do I add a battle pass to my server?

**Short answer:** install a battle pass plugin, such as **BattlePass**, then fill it with **tiers**, **quests** and **rewards**. Players complete quests to level up and unlock rewards, with an optional **premium pass** for extra cosmetic rewards.

***

### What makes a good battle pass

* **Many tiers**, so there is always a next reward close by.
* **Daily and weekly quests**, so players have a reason to log in every day.
* **Fair rewards.** Cosmetics and fun items, nothing that makes the premium pass pay-to-win. See [making money without pay-to-win](how-to-make-money-without-pay-to-win.md).
* **A season length** that fits your server, with a fresh pass each season.

{% hint style="info" %}
Setting up 100 tiers and enough quests takes a lot of time. A ready-made configuration saves you days of work.
{% endhint %}

More info: [BattlePass docs](https://battlepass.advancedplugins.net).
