# How do I sell a premium currency on my server?

**Short answer:** create a currency on your server with a plugin, sell bundles of it in your store, and let players spend it in-game. Follow Mojang's rules: the currency can't have real-world value or be cashed out.

***

{% stepper %}
{% step %}
### Add a currency to your server

Use a currency plugin to give players a second balance next to normal money, such as **coins** or **gems**.
{% endstep %}

{% step %}
### Sell bundles in your store

Create packages such as *100 coins*, *500 coins* and *1,000 coins*. Each package runs a command that adds the coins to the player's balance. Bigger bundles with a small bonus sell best.
{% endstep %}

{% step %}
### Let players spend it in-game

Add a menu where players spend coins on cosmetics, ranks or other fair rewards.
{% endstep %}
{% endstepper %}

### Mojang's rules for currencies

According to the [Minecraft Usage Guidelines](https://www.minecraft.net/en-us/usage-guidelines), a server currency:

* Can't have **real-world value** and can't be **cashed out**.
* Can't be **transferred to other servers**.
* Can't look like **Minecoins**.

What players spend it on must also follow the rules, see [making money without pay-to-win](how-to-make-money-without-pay-to-win.md).

***

Show each bundle with a bigger pile, bag or vault, so players see the value at a glance.
