# How do I add gift cards to my Tebex store?

**Short answer:** Tebex has gift cards built in. Create a package, turn on **Create Gift Card Upon Purchase** and set the value. The buyer gets a code by email, and anyone can redeem it at checkout.

***

### Sell gift cards as a package

1. In the Tebex Creator Panel, open **Webstore → Packages** and create a package.
2. Under **Options**, turn on **Create Gift Card Upon Purchase**.
3. Enter the gift card value, usually the same as the package price.

You can also create a gift card by hand under **Engagement → Gift Cards**, for example as a giveaway prize.

### How players redeem them

At checkout, the player types the code in the **coupon code** field and presses **Redeem**. If the card doesn't cover everything, they pay the rest normally.

Source: [Tebex gift cards docs](https://docs.tebex.io/creators/tebex-control-panel/engagement/gift-cards).

### Show them nicely

Our themes and Tebex websites include a **Gift Cards** add-on that shows your gift card packages as a clean set of cards. On legacy Tebex themes, the category needs **five** gift card packages to match the preview. See [Add-ons](../tebex-website-guides/add-ons.md).
