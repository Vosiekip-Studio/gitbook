# mcMMO or AuraSkills: which skills plugin should I use?

**Short answer:** both add RPG skills like mining, farming and fighting that level up as players play. **mcMMO** is the classic, known by almost every player. **AuraSkills** is more modern, with menus and stats built in and easier to customize. Want a Hypixel-style skills system? AuraSkills gets you closer out of the box.

***

### Side by side

|                     | mcMMO                                         | AuraSkills                                       |
| ------------------- | --------------------------------------------- | ------------------------------------------------ |
| Known for           | The classic skills plugin                     | A modern skills plugin with stats                |
| Menus               | Mostly chat commands                          | A skills menu built in                           |
| Customizing         | A few big config files                        | Separate files per skill, custom skills possible |
| Hypixel-style feel  | Needs extra menus                             | Closer out of the box                            |

### Pick mcMMO if…

Your players know and expect mcMMO, or you run an older server that already uses it. With extra menus (for example made with DeluxeMenus) it feels modern too.

### Pick AuraSkills if…

You start fresh and want skill trees, stats and a menu-based experience.

{% hint style="info" %}
Comparison based on both plugins' docs and [this comparison](https://mineguard.pro/en/blog/aurelium-skills-vs-mcmmo-rpg-comparison). Both get regular updates, so features change.
{% endhint %}
