# What is a lifesteal spawn, and what does it need?

**Short answer:** on a lifesteal server, players **steal a heart** when they kill someone and **lose one** when they die. The spawn is the hub where players gather, trade and fight. It needs a safe zone, crates, shops, portals and room for PvP.

***

### Must-have areas

| Area                    | Why                                                             |
| ----------------------- | --------------------------------------------------------------- |
| **Safe zone**           | Around the spawn point, so new players aren't killed instantly. |
| **PvP arena**           | Fighting is the core of lifesteal.                              |
| **Crystal PvP space**   | End crystals explode, so they need open room. See [crystal PvP arenas](what-should-a-crystal-pvp-arena-look-like.md). |
| **Crates**              | A central spot for crate keys.                                  |
| **Shops and NPCs**      | Where players buy and sell.                                     |
| **Portals to the wild** | So players get to the world quickly.                            |

### How big?

All of that needs space. Our lifesteal spawns are **501×501**, see [How big should a spawn be?](how-big-should-a-minecraft-spawn-be.md)
