# What should I sell on my Minecraft server store?

**Short answer:** start with **ranks** (cosmetic and quality-of-life perks), add **cosmetics**, and consider a **premium currency** players can spend in-game. Keep it simple and fair, and follow Minecraft's rules.

***

### Product ideas

| Product            | Why it works                                                       | Tip |
| ------------------ | ------------------------------------------------------------------ | --- |
| **Ranks**          | Easy to understand, players love a status upgrade.                 | Show every perk in a [rank table](how-to-add-a-rank-table-to-your-store.md). |
| **Cosmetics**      | Hats, particles and tags don't affect fairness.                    | See [cosmetics like hats](how-to-add-cosmetics-like-hats-to-your-server.md). |
| **Premium currency** | Players pick what they want in-game.                             | See [selling a premium currency](how-to-sell-a-premium-currency.md). |
| **Gift cards**     | Players buy for friends, great around holidays.                    | See [gift cards](how-to-add-gift-cards-to-your-tebex-store.md). |
| **Server boosts**  | A server-wide reward everyone enjoys.                              | Announce it in chat so others see it. |

{% hint style="warning" %}
Every product must follow Mojang's rules. See [How do I make money without pay-to-win?](how-to-make-money-without-pay-to-win.md)
{% endhint %}

### Make products look worth it

Players judge a package by its image. A clear, good-looking icon for each product makes your store feel professional.
