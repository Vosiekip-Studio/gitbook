# How do I make my Tebex store look better?

**Short answer:** you can tweak the default Tebex template yourself, install a ready-made **Tebex theme**, or run a complete **Tebex website** on your own domain. A theme is the quickest big upgrade, a website gives you the most control.

Every new Tebex store starts with the same default look. It works, but it looks like every other store, and players notice. A store that matches your server's style feels more trustworthy, and that helps sales.

***

### Option 1: Tweak the default template

In the Tebex Creator Panel, open **Appearance**. You can change your logo, colors and header image, and edit the template files if you know HTML and CSS.

* **Good for:** small changes on a tight budget.
* **Downside:** it still looks like a Tebex default store, and bigger changes need coding.

### Option 2: Install a Tebex theme

A theme replaces the whole design of your Tebex store: home page, packages, basket and extras such as a rank table, vote page or staff page. You install it once in the Tebex template editor and change texts and colors in the settings, no coding needed.

* **Good for:** most servers. A big visual upgrade in an afternoon.
* **How to install:** see our [Tebex theme installation guide →](../tebex-theme-guides/installation-guide.md).

### Option 3: Run your own Tebex website

A Tebex website is a complete website on your own domain, such as `store.mynetwork.com`. Your packages, payments and wallet stay in Tebex, but the design, pages, add-ons and translations are managed in your own admin panel.

* **Good for:** bigger servers that want full control and their own domain.
* **Needs:** cheap hosting and a domain, see our [Tebex website installation guide →](../tebex-website-guides/installation-guide.md).

***

### Which one should I pick?

| You want…                                  | Pick               |
| ------------------------------------------ | ------------------ |
| A quick, free improvement                  | Tweak the default  |
| A professional look without coding         | **Tebex theme**    |
| Your own domain and full control           | **Tebex website**  |
