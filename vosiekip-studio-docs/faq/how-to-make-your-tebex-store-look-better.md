# How do I make my Tebex store look better?

**Short answer:** tweak the default look in Tebex, or run your own **Tebex website** on your own domain. New Tebex stores can't use custom themes right now, so a Tebex website is the way to get a fully custom store. Already have an older store with Tebex Plus? Then a **Tebex theme** still works.

Every new Tebex store starts with the same default look. It works, but it looks like every other store, and players notice. A store that matches your server's style feels more trustworthy, and that helps sales.

***

### Option 1: Tweak the default look

In the Tebex Creator Panel, open **Appearance**. You can change your logo, colors and header image there.

* **Good for:** small changes on a tight budget.
* **Downside:** it still looks like a default Tebex store.

### Option 2: Run your own Tebex website (recommended)

A Tebex website is a complete website on your own domain, such as `store.mynetwork.com`. Your packages, payments and wallet stay in Tebex, but the design, pages, add-ons and translations are managed in your own admin panel. It works for **every** Tebex store, new or old.

* **Good for:** any server that wants a custom store and its own domain.
* **Needs:** cheap hosting and a domain, see our [Tebex website installation guide →](../tebex-website-guides/installation-guide.md).

{% hint style="info" %}
**Tebex websites for all our themes are coming soon.** Every one of our theme designs will be available as a Tebex website.
{% endhint %}

### Option 3: Install a Tebex theme (older stores only)

A theme replaces the whole design of your store: home page, packages, basket and extras such as a rank table, vote page or staff page.

{% hint style="warning" %}
**Only for older stores.** Tebex has turned off custom HTML and CSS for new stores on its new storefront system, and says it is working on bringing it back. Custom templates also need a **Tebex Plus** subscription. See [Tebex's Appearance docs](https://docs.tebex.io/creators/tebex-control-panel/webstore/appearance).
{% endhint %}

* **Good for:** stores on the older (legacy) webstore system with Tebex Plus.
* **How to install:** see our [Tebex theme installation guide →](../tebex-theme-guides/installation-guide.md).

***

### Which one should I pick?

| You want…                                         | Pick                  |
| ------------------------------------------------- | --------------------- |
| A quick, free improvement                         | Tweak the default     |
| A fully custom store on your own domain           | **Tebex website**     |
| A new design for an older store with Tebex Plus   | **Tebex theme**       |
