# How do I set up a dungeon with bosses on my server?

**Short answer:** start with a **dungeon build** that has rooms for each stage and boss, add the **bosses and mobs** with a custom mob plugin, then set up **rewards** and **protect** the area so players can't break it.

***

{% stepper %}
{% step %}
### Place the dungeon build

A progressive dungeon has a path from easy to hard, with mini bosses along the way and a final boss at the end. Paste it into its own area or world, see the [build installation guide →](../build-guides/installation-guide.md).
{% endstep %}

{% step %}
### Add bosses and mobs

Use a custom mob plugin to create bosses with their own health, attacks and drops, and spawn them in the boss rooms.
{% endstep %}

{% step %}
### Add rewards

Give loot when a boss dies, or put reward chests at the end. Fair rewards keep players coming back.
{% endstep %}

{% step %}
### Protect the dungeon

Stop players from breaking or skipping parts of the dungeon with a region plugin, see [How do I protect my spawn from griefing?](how-to-protect-your-spawn-from-griefing.md)
{% endstep %}
{% endstepper %}
