# How do I add a Hypixel-style bazaar?

**Short answer:** use the **DeluxeBazaar** plugin. Like Hypixel SkyBlock's bazaar, players place **buy and sell orders**, and prices are set by the players themselves instead of a fixed shop.

***

### Bazaar or shop?

|                  | Shop                          | Bazaar                                      |
| ---------------- | ----------------------------- | ------------------------------------------- |
| Prices           | Fixed, set by you             | Set by players through orders               |
| Trading          | Players trade with the server | Players trade with each other               |
| Best for         | Survival, lifesteal           | Skyblock and economy-focused servers        |

### What you need

* **DeluxeBazaar** on your server.
* **Vault** and an economy plugin.
* **Categories and items** that fit your server. A good setup groups items like farming, mining and combat, and only lists items worth trading.
