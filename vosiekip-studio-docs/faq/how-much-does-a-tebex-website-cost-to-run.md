# How much does it cost to run a Tebex website?

**Short answer:** besides the website itself, you pay for **hosting** and a **domain**. Both can be cheap: budget web hosting with Node.js support and a domain cost a few dollars to a few tens of dollars per year. Tebex's normal sales fees apply, just like on any Tebex store.

***

### What you pay for

| Cost            | What it is                                           | Tip                                                          |
| --------------- | ---------------------------------------------------- | ------------------------------------------------------------ |
| **Hosting**     | The computer that keeps your website online.         | Web hosting with cPanel and Node.js is enough, see [Choosing your hosting](../tebex-website-guides/installation-guide.md). |
| **Domain**      | Your store's address, such as `mynetwork.com`.       | Already own one? Use a free subdomain like `store.mynetwork.com`. See [Setting up your domain](../tebex-website-guides/setting-up-your-domain.md). |
| **Tebex fees**  | Tebex's platform fee and payment provider fees per sale. | The same as for any Tebex store, see [Tebex's fees](https://docs.tebex.io/creators/pricing-overview/tebex-fees-and-billing-overview). |

{% hint style="warning" %}
**Check the renewal price.** Hosting and domains are often very cheap for the first year and more expensive after that.
{% endhint %}

### What you don't need

* **No Tebex template.** The design lives on your own website, so you don't use Tebex's custom template feature.
* **No developer.** Our [installation guide](../tebex-website-guides/installation-guide.md) walks you through every step, or [we can help](../tebex-website-guides/giving-us-access.md).
