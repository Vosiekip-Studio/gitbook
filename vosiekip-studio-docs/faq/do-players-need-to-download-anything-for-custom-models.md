# Do players need to download anything to see custom models?

**Short answer:** no mods. When a player joins, Minecraft asks if they want to use the server's **resource pack**. They press **Yes**, and the custom models show up. It downloads automatically.

***

### How it works

1. Your custom item plugin builds a resource pack with all the models and textures.
2. When a player joins, the server sends the pack.
3. The player accepts it, and Minecraft loads it while they're on your server.

### If a player doesn't see the models

* In Minecraft, open **Multiplayer**, select your server, press **Edit** and set **Server Resource Packs** to **Enabled**.
* Rejoin the server.

See [Why are my custom items purple and black?](why-are-my-custom-items-purple-and-black.md)

{% hint style="info" %}
Resource packs are a **Java Edition** feature. Bedrock players who join through a crossplay plugin need extra setup to see custom models.
{% endhint %}
