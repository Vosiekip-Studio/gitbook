# Tebex theme or Tebex website: what's the difference?

**Short answer:** a **Tebex theme** changes the design inside Tebex itself. A **Tebex website** is your own website on your own domain that shows your Tebex packages. Themes need Tebex Plus and a legacy store, a website works for every store.

***

### Side by side

|                         | Tebex theme                                   | Tebex website                                           |
| ----------------------- | --------------------------------------------- | ------------------------------------------------------- |
| Where it runs           | Inside Tebex                                  | On your own hosting                                     |
| Address                 | `yourstore.tebex.io` (own domain needs Tebex Plus) | Your own domain, such as `store.mynetwork.com`     |
| Works on new Tebex stores | No, not right now                           | Yes                                                     |
| Needs Tebex Plus        | Yes                                           | No custom Tebex template needed                         |
| Where you change settings | Tebex **Appearance**                        | Your website's own **admin panel**                      |
| Extra costs             | Tebex Plus subscription                       | Hosting and a domain                                    |
| Packages, payments, wallet | Tebex                                      | Tebex                                                   |

### Pick a Tebex theme if…

You have an older (legacy) Tebex store with Tebex Plus and just want a new design. See the [Tebex theme installation guide →](../tebex-theme-guides/installation-guide.md).

### Pick a Tebex website if…

You have a new store, want your own domain, or want more control: translations, sidebar modules and add-ons in your own admin panel. See the [Tebex website installation guide →](../tebex-website-guides/installation-guide.md).
