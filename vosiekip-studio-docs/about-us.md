# About us

### How it all started

Vosiekip Studio started as a fun Minecraft server project. After a few successful servers, we moved to pre-made products, which is now our main work. We make affordable, unique products that are easy to set up.

We believe anyone can build the server they dream of, as long as they dare to start the Minecraft server development journey, one that never stops.
